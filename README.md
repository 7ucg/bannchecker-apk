## Which APK Should I Use?

| APK | Use this if... |
| --- | --- |
| `arm64` | You have a modern Android phone or tablet. This is the best choice for most users. |
| `arm` | You have an older 32-bit ARM Android device. |

## Install Notes

- If you are unsure, try `arm64` first.
- If that does not install on your device, use `universal`.
- You may need to allow installation from unknown sources in Android settings before opening the APK.
