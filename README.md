## Which APK Should I Use?

| APK | Use this if... |
| --- | --- |
| `arm64` | You have a modern Android phone or tablet. This is the best choice for most users. |
| `arm` | You have an older 32-bit ARM Android device. |

## Install Notes

- **Updating from an older version?** This build is signed with a new key, so
  Android will not install it over an existing BanChecker. Uninstall the old
  app first, then install this APK. On-device app data is cleared on uninstall.
- If you are unsure which APK to pick, try `arm64` first; use `arm` if it does
  not install.
- You may need to allow installation from unknown sources in Android settings
  before opening the APK.
